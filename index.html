01

The Vibe

Vermilion red on warm black, every surface cut like torn paper, every headline shoved eight degrees off the vertical, and drop shadows with zero blur, the way ink sits on a poster. Most interfaces go soft: pale grounds, rounded cards, a friendly sans. This one goes the other way. It behaves like a title sequence that happens to be clickable.

Restraint is what makes the one weapon land. The ground stays nearly monochrome, so a single vermilion shard reads as an event. Cyan appears when something is confirmed. Amber when something is pending. Nothing else gets a colour.

02

Best For / Avoid If

+ Best For

  • Products built around one hero action: capture, scan, start, submit
  • Audiences who already love game UI and want software that feels like it
  • Timers, streaks, levels, anything with progress worth dramatising
  • Short bursts of use rather than all-day sessions
  • Brands with the nerve to be loud and specific
  • Marketing surfaces that need to stop a scroll cold

× Avoid If

  • Your screens are dense tables or long-form reading. Skewed type and clipped shards fight information density
  • You need to read as trustworthy and institutional; this trades credibility for swagger, on purpose
  • Your audience needs a light theme. This world is dark only, and inverting it collapses it
  • Accessibility budget is thin: it leans on custom focus rings, and every shard needs contrast checked by hand
  • The product is calm by nature: sleep, meditation, anything anxiety-adjacent
03

Design Philosophy

Ordered by how load-bearing each rule is. Break 01 and the aesthetic is gone; break 04 and it just gets noisy.

01

Nothing is a rectangle, nothing is rounded

Every surface is cut with a clip-path into a torn-paper shard, and border-radius is zero on every element. This single rule does more work than the colour does. A rounded corner anywhere reads as a different product entirely.

02

Eight degrees, always the same eight

Display type, buttons, tags, nav items and gauge tracks all skew -8deg; inner text un-skews by the same amount so it stays readable. Panels rotate a further -1.5deg. Repeating one angle reads as attitude. Random angles just read as broken.

03

Red is a weapon, not a background

Vermilion marks exactly one thing per view: the action you're meant to take, or the step you're on. Keep it under roughly 15% of any screen. The moment red becomes a surface colour it stops signalling anything.

04

One orchestrated moment, everything else micro

Motion is fast in and slower out: 120ms snap with a touch of overshoot, 420ms to settle. Each screen gets a single choreographed beat and nothing else animates for its own sake. Anything beyond that beat competes with it.

Use With Claude

Claude

  1. Open Customize, then Skills
  2. Create a skill and upload SKILL.md
  3. Add DESIGN.md, tokens.css and components.css to the project knowledge base
  4. Name the system while you build. Claude applies it from there

Claude Code / Cursor

  1. Drop the design-system/ folder in your repo
  2. Reference SKILL.md and DESIGN.md from CLAUDE.md (or .cursor/rules)
  3. Import tokens.css then components.css in your global stylesheet
  4. Build normally. Name the system to invoke it
★ Pro tip

Ask for the shard geometry before the colour. If you let a model start from “red and black,” you get a red-and-black bootstrap page. If you make it start from clip-path silhouettes, zero radius and the −8° skew, the palette lands on top of a structure that's already correct.

06

Watch Out For

!

Skewed text that never un-skews

Buttons and nav items skew the container, so the label inside has to skew back by +8deg or the type comes out warped. Every component does this with a .p5-btn > * rule. Keep it when you build new ones.

!

Halftone loud enough to eat the text

The dot grid belongs under the copy at about .16 alpha. Push it past roughly .25 and body text stops being comfortable to read while still technically passing contrast.

!

Pure #E60012 on small type

The signature red is 3.4:1 on the ground, which fails for labels and captions. Fills and borders use --p5-red; anything set small uses --p5-red-text at 5.3:1.

!

Soft shadows creeping back in

A blurred shadow turns this into a generic dark dashboard. Shadows are hard offsets with zero blur in #8E0009 or black. Any blur radius above 0 is wrong.

!

Red as a surface

The fastest way to kill this system is to make red the card background because it's the brand colour. Red marks one thing per screen. Everything else is soot, ember and bone.

!

Rotated elements bleeding out of layout

Anything with rotate() throws its corners past its own box. The marquee sits inside .p5-marquee-clip for exactly this reason. Wrap every tilted band the same way.

!

Off-the-shelf icon sets

Rounded Lucide or Heroicons fight every other line on the page. Icons here are angular, chisel-tipped, drawn on the same −8° grid, or they're type set in Anton instead.

!

Invisible focus states

Skewed clip-path elements clip a default browser outline into nothing. Every interactive element needs the explicit cyan outline: 3px solid #17E0D6 with an offset. This is the accessibility cost of the aesthetic and it isn't optional.

07

Pairs Well With

Type

Anton with Archivo is the house pair. Swap Anton for League Gothic or Oswald if you need more weights; keep the condensed width and the skew.

Texture

9px halftone dot grids and −58° slash hatching, both at very low opacity. Riso-style misregistration if you want print energy.

Imagery

Hard flash, deep shadow, subjects cropped tight. Duotone the misses into red and black rather than dropping them.

Motion

CSS transitions carry almost all of it. Reach for GSAP only for the hero moment, the one worth choreographing.

Sound

Short percussive acid-jazz stabs on confirm. The aesthetic has an audio half and skipping it leaves the product quieter than it looks.

Adjacent looks

Brutalist web, Y2K rave flyers, manga panelling, Swiss poster grids pushed off-axis.
